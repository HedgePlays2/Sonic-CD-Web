# Sonic CD Web

A web version of **Sonic CD**, originally made by Crush Arcade.

**Play online:** https://hedgeplays2.github.io/Sonic-CD-Web/

## Controls

### Keyboard
- **Arrow keys:** Move
- **Z:** Jump
- **Enter:** Start / confirm

### Touch controls
- On-screen directional buttons for movement
- **JUMP** sends the **Z** key
- **START** sends **Enter**

The START button is positioned beneath JUMP for easier use on touchscreens.

## Credits

The original web port was made by **Crush Arcade**. This repository hosts the web version and additional adjustments, including touchscreen controls.
